← Admin Tools Import from another Nightscout instance

Pulls entries, treatments, devicestatus, profile, food, activity, and subjects/roles (API tokens) from an existing Nightscout site's REST API into this deployment. Runs in the background in paginated batches (a Durable Object alarm loop), so it's safe for years of history. Authenticate the pull with either the source's API_SECRET (hashed before sending, never stored) or a subject/access token — a token is the safer choice since it doesn't expose the source's master secret, but importing subjects specifically needs one with admin rights on the source (subjects/roles are an admin-only endpoint there too). Imported subjects get a brand-new access token on this deployment — the source's token values themselves can't carry over, since each token is derived from its own deployment's secret — so any existing shared follower links will need to be regenerated from this site's Admin Tools afterwards.
